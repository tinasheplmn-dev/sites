het probleem

Waardevolle data, opgesloten in één systeem.

Het begint klein: een partner die "even een exportje" vraagt. Een Excel die wekelijks wordt rondgemaild. Een koppeling die iemand ooit met de database heeft geknutseld, en die niemand meer durft aan te raken.

Zo lekt er tijd, en erger: controle. Wie kan er eigenlijk bij jullie data? Een goede API draait dat om. Andere applicaties kunnen aansluiten via één nette, gedocumenteerde voordeur, en jullie bepalen per afnemer wat die mag zien. Ook voor open data en mobiele apps is dat de enige route die schaalbaar én veilig is.

de aanpak

Contract eerst, code daarna.

Verkennen

Welke data moet naar buiten, wie zijn de afnemers en welke identity provider gebruiken jullie al? Eén sessie, daarna ligt de scope vast, met prijs.

Ontwerpen

We ontwerpen het API-contract vóór er code staat: endpoints, datamodellen, rechten. Als OpenAPI-specificatie, zodat jullie team kan meelezen en afnemers vast kunnen bouwen.

Bouwen

De API in C#/.NET, beveiligd met JWT-tokens via jullie eigen identity provider. Elke endpoint getest, documentatie die automatisch meegroeit met de code.

Overdragen

Deploy-pipeline, broncode en documentatie: alles is van jullie. Inclusief overdracht aan jullie ontwikkelaars, zodat je niet aan ons vastzit.

wat je krijgt

Deliverables.

REST-API in C#/.NET

Modern .NET, LTS-versies, klaar voor jaren productie. Geen framework-experimenten met jullie data.

OpenAPI-documentatie

Automatisch gegenereerd uit de code, dus altijd actueel. Afnemers kunnen direct aan de slag.

JWT-beveiliging via jullie provider

Aansluiting op Microsoft Entra ID, ADFS, Auth0 of Okta. Jullie beheren de toegang, per afnemer.

Pipeline & broncode

Automatische uitrol via Azure DevOps en volledige eigendom van de code. Vertrek-garantie inbegrepen.

veelgestelde vragen

Eerst nog even dit.

Wat kost een API?

Een Basis-API kost €3.000, een Uitgebreide API €7.000 (beide excl. btw). Voor specifieke wensen maken we een custom offerte. Altijd een vaste prijs vooraf, dus geen verrassingen achteraf.

Kunnen jullie aansluiten op onze bestaande identity provider?

Ja. We koppelen de API aan Microsoft Entra ID, ADFS, Auth0 of Okta. Jullie beheren zelf wie toegang krijgt, per afnemer.

Van wie is de code na oplevering?

Volledig van jullie: broncode, deploy-pipeline en documentatie. Inclusief overdracht aan jullie eigen ontwikkelaars, zodat je nergens aan vastzit.

Onze data staat in een verouderd systeem. Kan dat?

Ja. Juist dan is een API waardevol: het oude systeem blijft staan, de API vormt de nette, veilige voordeur ervoor.

Hoe lang duurt het bouwen van een API?

Dat hangt af van het aantal bronnen en de rechtenstructuur. Na het verkennende gesprek krijg je bij de offerte ook een concrete planning.
