04 · het werk

Zo ziet zorgvuldig eruit.

Veiligheid zit niet in een sticker, maar in de architectuur. Authenticatie via Entra ID, autorisatie per endpoint, documentatie die zichzelf genereert. Dit is geen demo-code. Dit is hoe elke Smartersoft-API begint.

Zo bouwen wij API's →
Program.cs · rooster-api
// Minimal API, beveiligd met Microsoft Entra ID
var builder = WebApplication.CreateBuilder(args);

builder.Services
    .AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddMicrosoftIdentityWebApi(builder.Configuration, "AzureAd");

builder.Services.AddAuthorization();

var app = builder.Build();
app.UseAuthentication();
app.UseAuthorization();

app.MapGet("/v1/rooster/{klas}",
        async (string klas, IRoosterService rooster) =>
            Results.Ok(await rooster.GetWeekAsync(klas)))
    .RequireAuthorization("Rooster.Read");

app.Run(); // → 200 OK
